# 2103307 MFR Product Realization [2026]

Welcome to the official resource repository for **2103307 MFR Product Realization**. This repository is designed to support students in their journey from conceptual design to physical manufacturing.

As your TA, I will keep this repo updated with all necessary digital assets and technical documentation required for the course.

---

## 📂 Repository Contents

* **Lecture Slides:** Weekly presentation materials in PDF format.
* **CAD Models:** Reference parts, standard components, and assembly examples (STL, STEP, and Fusion 360 files).
* **Machine Parameters:** Verified slicer profiles, motor tuning values, and material spec sheets.
* **Code & Scripts:** Helper scripts for ROS2, sensor integration, and automation tasks.
